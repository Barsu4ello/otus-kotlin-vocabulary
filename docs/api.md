# API — Vocabulary Trainer

## 1. Сущности

### Word (Слово)

| Поле | Бизнес-описание | Пример |
|------|----------------|--------|
| id | Уникальный идентификатор слова | "word_123" |
| userId | Владелец слова (пользователь) | "user_1" |
| english | Слово на английском языке | "apple" |
| russian | Перевод на русский язык | "яблоко" |
| partOfSpeech | Часть речи | "noun" |
| createdAt | Дата добавления | "2026-04-24T10:00:00" |

---

## 2. Бизнес-функции (методы)

### CRUD для слов (words)

---

### words.create — Добавление нового слова

**Бизнес-правило:**
- пользователь может добавлять слова в личный словарь
- слово должно содержать минимум английскую и русскую часть

**Ограничения:**
- english: минимум 1 символ
- russian: минимум 1 символ
- partOfSpeech: обязательное поле

---

### words.read — Получение слов пользователя

**Бизнес-логика:**
- возвращает список слов конкретного пользователя
- сортировка по дате добавления (новые сверху)

**Ограничения доступа:**
- пользователь видит только свои слова

---

### words.update — Обновление слова

**Бизнес-правило:**
- только владелец слова может его изменить

**Что можно менять:**
- перевод на русский язык
- английское слово
- часть речи

---

### words.delete — Удаление слова

**Бизнес-правило:**
- удаление доступно только владельцу
- слово удаляется полностью из словаря

---

### words.search — Поиск по словам

**Бизнес-логика:**
- поиск по английскому или русскому слову
- поддержка частичного совпадения

**Фильтры:**
- часть речи (опционально)

---

## 3. Бизнес-правила

### Доступ к данным

- пользователь имеет доступ только к своему словарю
- слова не доступны другим пользователям

---

### Валидация данных

- английское слово обязательно
- перевод обязателен
- часть речи: noun, verb, adjective, adverb и тд.(ограниченный список)

---

### Ограничения пользователя (MVP)

- максимум 1000 слов на пользователя
- лимит 100 запросов в минуту

---

- количество добавленных слов на пользователя

## 6. Ограничения системы

- слова принадлежат только одному пользователю
- нет публичных словарей (MVP)
- нет совместного редактирования
