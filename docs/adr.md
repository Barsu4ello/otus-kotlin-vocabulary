# ADR: Контекстная архитектура Vocabulary Trainer

## Контекст системы

Система Vocabulary Trainer предназначена для хранения и управления персональным словарём пользователя и подготовки данных для обучения иностранным словам.

---

## Участники системы

### 👤 Пользователь
- добавляет новые слова в словарь
- просматривает список слов
- редактирует и удаляет слова
- использует слова для будущих тестов

---

##  Аутентификация и авторизация

###  Envoy Proxy
Envoy выступает как API Gateway между пользователем и backend системой.

**Функции:**
- перехват всех входящих HTTP/gRPC запросов
- проверка JWT токенов через Keycloak
- маршрутизация запросов в Vocabulary Trainer API
- базовые политики безопасности (rate limiting, фильтрация запросов)

---

###  Keycloak
Система управления аутентификацией и авторизацией (IAM).

**Функции:**
- регистрация и авторизация пользователей
- выдача access и refresh JWT токенов
- управление ролями
- хранение информации о пользователях



---

##  Vocabulary Trainer API (Backend система)

Центральный компонент системы.

**Функции:**
- обработка CRUD операций со словами
- валидация входных данных
- фильтрация данных по userId
- подготовка данных для будущих тестов
- проверка авторизации на уровне бизнес-логики

---

##  База данных (Storage)

- хранение слов пользователей
- связь userId → слова
- обеспечение персистентности данных

---

##  Логирование и наблюдаемость

###  Fluent Bit

**Функции:**
- сбор логов из приложений
- парсинг и нормализация логов
- пересылка логов в OpenSearch

---

###  OpenSearch

Система централизованного хранения и анализа логов.

**Функции:**
- хранение логов всех сервисов
- быстрый поиск по логам
- анализ ошибок и инцидентов
- построение дашбордов (через OpenSearch Dashboards)
