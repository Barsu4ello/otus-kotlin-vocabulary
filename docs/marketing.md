# Маркетинг и аналитика

## Проблема
Людям сложно запоминать новые иностранные слова.

## Решение
Приложение Vocabulary Trainer позволяет:
- сохранять слова
- структурировать их
- проходить тесты по сохраненным словам (💬 в будущем)

## Конкуренты
- Duolingo
- Quizlet

## Наше отличие
- простой минималистичный словарь
- персональная база слов
